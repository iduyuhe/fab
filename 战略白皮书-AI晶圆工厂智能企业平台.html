一句话定位

构建一个以 AI Agent 为核心、专门服务于 AI 芯片（晶圆）工厂 的智能企业操作系统， 通过 社区 → 教学 → 专业 → 工厂 四级演进，从"开源可玩"逐级升档到"真实部署"， 用前两级养出的 AI 能力与生态反哺后两级，最终落地"面向新时代的智能企业"。

一、核心认知：四级是"同一底座的四种交付形态"

四级不是"功能由少到多"的线性堆叠，而是同一套底座按"可信度 / 复杂度 / 合规要求"逐级升档。 每一级都复用下一级的底座，但通过替换关键组件实现跃迁：

  • 工厂级不是最高级，而是"约束最多"的一级——合规、安全、标准、可靠性要求最高。
  • 社区级与教学级反而是"铺量、建生态、养模型"的土壤——这是"面向新时代智能企业"的杠杆点：用生态养能力，反哺工厂级。

二、四级边界设计

L1 社区级（Community）—— 开源、轻量、可玩

  • 形态：单文件 / 一键部署（Docker 一条命令），前端用既有 twin.html 系列做"晶圆厂沙盘"。
  • AI Agent：对话式助手——"用自然语言让你看到光刻机瓶颈""讲讲 SPC 是什么"。
  • 去工业化：SQLite 即可、无鉴权、无合规负担。
  • AI 芯片针对性：内置"AI 芯片典型工艺路线（5nm/3nm 逻辑、HBM 堆叠）"为默认场景。
  • 价值：生态入口、训练数据来源、品牌建设。

L2 教学级（Educational）—— 课程化、实验化

  • 形态：在社区级上加"课程模块 + 实验台 + 评测"。 例：实验一"用 SPC 拦截一次光刻 CD 漂移"；实验二"APS 排程让交期达标"。
  • AI Agent：带教导师——学生做错步骤，Agent 提示但不代做；可生成个性化错题讲解。
  • 工艺库：引入 SEMI 标准工艺段、真实典型配方（脱敏）。
  • 价值：院校合作、人才输送、标准心智占领。

L3 专业级（Professional）—— 工程可用、可接真实

  • 形态：拆架构（解决单进程→微服务痛点）、加 OPC-UA / EDA 适配器。
  • AI Agent：协作副驾——自动跑 what-if、生成排程方案、标记异常根因，每步留"人确认"锚点。
  • 模型升级：SPC 补 Cpk/Ppk、PdM 补 RUL、VM 补置信区间。
  • 价值：工程师日常工具、替代部分老旧 MES 模块、商业变现起点。

L4 工厂级（Fab）—— 真实部署、合规自治

  • 形态：多工厂 / 多租户、ISA-95 建模、等保 / 21 CFR Part 11、高可用。
  • AI Agent：自治体群——设备健康 / 排程 / 质量 Agent 协同，人在回路监督异常升级。
  • 闭环：真实 PLC/设备数据 → 孪生 → 决策 → 回写控制（APC 闭环）。
  • 价值：真正的"智能企业"落地。

三、AI Agent 三层架构（贯穿四级的关键）

战略层 Agent（厂长大脑）：产能规划、经营决策、跨域协调。
领域层 Agent（专家群）：SPC 质量 / PdM 设备 / VM 量测 / APS 排程 / ERP 成本——各为一个专业 Agent。
执行层 Agent（设备协作者）：单设备 / 单产线的实时监视与微决策。
  • 社区 / 教学级：主要跑"领域层 Agent 的讲解态" + 战略层 Agent 的演示态。
  • 专业级：领域层 Agent 进入"协作态"（半自治）。
  • 工厂级：三层全激活，执行层 Agent 7×24 在线。
AI 芯片晶圆厂的 Agent 特殊性：良率（yield）是生死线，故"质量 Agent"与"量测 VM Agent"优先级最高； AI 芯片工艺（EUV 多重曝光、HBM 堆叠）的复杂度，使"排程 Agent"比传统 fab 更值钱。

五、战略路线图建议

建议先打"社区级 + 教学级"组合拳
  • 零合规负担、能立刻出产品，且能反哺 AI 模型（生态数据）。
  • 现有演示系统改造成"社区级沙盘"工作量小（主要打包 + 对话 Agent 接入）。
  • 教学级是半导体人才培养刚需，市场空白明显，易建立标准心智。
  • 工厂级门槛高、周期长，不宜作为第一枪；但用 L4 架构思想反向约束 L1–L3 的数据模型，避免返工。

六、待拍板的关键决策

  1. 先做哪一级 MVP？ 建议"社区级沙盘"先做（快速出活、验证 Agent 接入范式）；若有院校资源，教学级变现更快。
  2. AI Agent 形态？ 接大模型 API（对话式 Copilot） vs 轻量"规则 + 检索"Agent（可控、零 API 成本）——决定 L1 部署门槛。
  3. "AI 芯片"针对性深度？ 场景模板层（默认加载 AI 芯片工艺路线）vs 物理模型层（真实 EUV/刻蚀机理，属 L3/L4）。L1 至少"看起来对"。

七、战略结论

我们已建成一个架构思路现代、闭环验证完整的演示级智能工厂平台。 本战略将其重新定位为：以 AI Agent 为核心、专为 AI 芯片晶圆厂打造、分四级演进的智能企业操作系统。 用社区与教学级"铺量养能力"，用专业与工厂级"落地变现"—— 四级共享同一底座，逐级替换关键组件，是从"演示闭环"走向"工业上岗"的最短路径。
